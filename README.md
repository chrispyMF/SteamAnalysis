**PROJECT IDEAS**

**Name:** Steam Analysis (WIP)  
**One-line description:** A cloud-hosted web app utilizing machine learning to generate personalized game recommendations for users by analyzing their game library and play history.

**PROBLEM**

**What problem does this solve?**  
Many gamers have large Steam libraries and struggle to decide what to play next. Recommendations are typically either biased or based purely off of popularity without accounting for a user’s preferences.

**Who is it for?**  
PC Gamers with medium to large Steam libraries who want personalized game recommendations rather than generic trending ones.

**GOALS**

1. Deploy a fully functional cloud-hosted web app  
2. Produce clean, maintainable, and well-documented code  
3. Build a project suitable for inclusion on a resume  
4. Demonstrate experience in:  
   1. Full-stack development  
   2. Cloud deployment  
   3. API integration  
   4. ML pipelines

**CORE FEATURES (MVP)**

1. User Data Ingestion  
   1. Collect user data through Steam Web API  
2. Game Metadata Integration  
   1. Retrieve aspects like genre, tags, and other attributes from IGDB  
3. Web Interface  
   1. Allows users to easily interface with the app without installing software  
4. Cloud Deployment  
   1. Hosted and deployed using AWS

**TECH STACK (tentative)**

**Frontend:** React + Vite  
**Backend:** C++ for Steam Web API  
**Database:** Not needed initially, needed for later analysis  
**Hosting / deployment:** AWS
